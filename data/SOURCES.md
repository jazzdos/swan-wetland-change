The DEA Waterbodies row records two checksums. The full-payload checksum is computed by `scripts/fetch_aoi.py::stable_geojson_checksum`, because the WFS adds a `timeStamp` that changes on every request. The approved design keeps every feature property, including the refreshable ones (`dt_wetobs`, `dt_satpass`, `dt_updated`, `wet_sa_m2`), so a DEA data refresh can change the full checksum without any polygon change. The geometry checksum is computed by `scripts/fetch_aoi.py::geometry_checksum` over the uid and geometry of every feature only, so it is the polygon confirmation: the same value means the same uids and boundaries. The full checksum was 7d993aa8 on 2026-10-29 and 5e83c045 on 2026-11-06 with the same geometry checksum, and the 2026-11-02 backfill copy has the same geometry checksum. The Ramsar row remains a raw-bytes sha256. Fixture rows list a sha256 per file; tests/test_sources.py checks them against the files and checks that every host named in src and scripts appears in a table row of this file.
