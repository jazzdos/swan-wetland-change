The DEA Waterbodies checksum is computed by `scripts/fetch_aoi.py::stable_geojson_checksum`, because the WFS adds a `timeStamp` that changes on every request. The Ramsar row remains a raw-bytes sha256. The approved design keeps every feature property, including the refreshable ones (`dt_wetobs`, `dt_satpass`, `dt_updated`, `wet_sa_m2`), so a DEA data refresh can change this checksum without any polygon change. A changed value means "the payload changed", not "a boundary changed"; confirm geometry separately. Fetches on 2026-11-03 still gave 7d993aa8, so no refresh had changed it by then.
