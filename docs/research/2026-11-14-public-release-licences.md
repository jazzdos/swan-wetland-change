# Public release licences, 2026-11-14

This note is the evidence for step 2 of "Reopening public access" in docs/decisions/0011-private-output-bucket.md (story st-1a9c): every dataset in data/SOURCES.md must have redistribute_public true, and the attribution and ShareAlike terms must be met in the published files. It records evidence only. Whether a licence is acceptable is Jarrod's decision.

Scope is the objects the pipeline writes to the output store. Repository files (docs/research, tests/fixtures, README) are out of scope, and changing the repository's visibility is out of scope. The method is a read of the writer code and tests at commit e3890a6, plus the offline outputs in the Offline evidence section. No output-store object was read, no AWS call was made, and no verification report or CI run log was opened. Pages were fetched on 2026-11-14 with a generic client that carried no user, email or project name.

## Question for Jarrod

> DBCA-010 licence. Three checks against DBCA's catalogue entry and the SLIP service terms confirmed CC BY-SA 4.0 in 0 of 3. The primary sources state: "Creative Commons Attribution Non-Commercial 4.0" (https://catalogue.data.wa.gov.au/dataset/ramsar-sites, 2026-11-14); "You are not permitted to, in any form, reproduce, distribute, commercialise or create derivative works of this data without the data custodians prior written permission." (https://public-services.slip.wa.gov.au/public/rest/services/SLIP_Public_Services/Environment/MapServer?f=pjson, 2026-11-14). The only CC BY-SA 4.0 label is on the data.gov.au aggregator (https://data.gov.au/data/dataset/ramsar-sites, 2026-11-14).
